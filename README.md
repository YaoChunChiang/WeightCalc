# 槓鈴計算器：輸入重量，槓片自動配好

**一句話介紹**
輸入想做的重量，馬上看到兩邊要掛哪些槓片。組數、次數和休息時間也能一起記。

---

## 你是不是也遇過這些狀況？

1. **組間還在心算**
   「目標 87.5 公斤，扣掉 20 公斤的槓，一邊 33.75……要掛哪幾片？」喘著氣算數學，休息時間就這樣用掉了。
2. **計算器算得出來，但健身房沒有那些片**
   一般計算器假設每種槓片都有。實際上 2.5 公斤的片常常被別人拿走，或是你只想用槓上已經有的 20 公斤。
3. **課表寫 5RM，還要先換算成重量**
   課表寫百分比或 RM，你得先算出重量，再算槓片，而且算出來的常常是 66.4 這種掛不出來的數字。
4. **記錄 app 太複雜**
   要註冊、要選課表、要點好幾層選單。你只想在兩組之間快速記下「100 公斤 × 5 下」。
5. **休息計時要另外開一個 app**
   計時器和記錄分開，休息多久常常忘了記。

## 槓鈴計算器怎麼解決

### 🎯 輸入總重，自動配片
- 輸入目標重量，系統會算出**片數最少**的組合，並畫出整根槓鈴。
- 不想打字的話，在重量欄上左右滑動就能調整：慢滑 ±1、快滑 ±5，旁邊的按鈕一次 ±5。
- 湊不到剛好的重量時，會給出**不超過目標的最接近重量**，並標出差多少。
- 支援 kg / lb，可選 15 / 20 公斤（35 / 45 磅）的槓，也能自訂槓重。

### 🔒 依照健身房現有的槓片來配
這是其他計算器很少做到的：
- **點一下槓片 = 不用這個重量**：沒有 2.5 公斤的片？點掉它，系統改用其他組合。
- **長按槓片 = 固定使用**：想保留兩片 20 公斤？鎖定後，系統只計算剩下的部分。
- 調整後如果目標重量降低、裝不下鎖定的片，會先減少最後鎖定的那片並提示你。

### 📊 RM 模式：輸入 1RM，直接算到槓片
- 輸入 1RM，選擇 1～15RM（依 NSCA 換算表），重量和槓片一次算好。
- 算出來的重量會調整成掛得出來的整數，接近 5 的倍數時就取 5 的倍數，例如 69.6 → 70。
- 每個 RM 都會算出不同的重量，不會出現兩個 RM 結果一樣。
- 也可以反過來：點中間的箭頭切到 ←，在結果欄輸入 N RM 的重量，自動回推 1RM。這時換 RM，填的重量不會變，改成重算 1RM；選單裡也會直接列出每個 RM 推出來的 1RM。
- 箭頭指向的那格是算出來的（淡色、不能改）；另一格可以輸入，也能左右滑動調整。

### 🧭 第一次打開有操作導覽
- 逐步框亮每個功能並說明手勢；右上角「?」可以隨時重看。

### 🎨 和實際槓片一樣的顏色
- 依照常見的競賽槓片配色：紅 25、藍 20、黃 15、綠 10、白 5。小槓片用同色系的淺色區分。
- 槓片由重到輕從內往外排，和實際掛片的順序一樣，看一眼就知道怎麼掛。

### 📝 訓練記錄和組間計時
- 內建常用的槓鈴動作（蹲舉、硬舉、臥推、肩推、划船……），也能新增自訂動作。
- 重量和次數在數字上左右滑動調整（慢滑 ±1、快滑重量 ±5，兩側箭頭點一下 ±1，點數字可直接輸入），一隻手就能按「✓ 記錄一組」。
- **記錄後自動開始休息計時**，可選正計時或倒數，倒數結束會震動提醒。
- 每組的休息時間會自動記下來；相同重量和次數的組會合併顯示。
- 練完按「複製紀錄」，可以直接貼給教練或存到筆記。

### ↶ 隨時可以復原
放錯片、點錯都能一步步復原，最多可以退回 60 步。

## 和其他 App 的不同

| | 一般槓片計算器 | 一般訓練記錄 App | **槓鈴計算器** |
|---|---|---|---|
| 依現有槓片配重（封鎖／鎖定） | ✗ | ✗ | **✓** |
| RM 換算後直接算出槓片 | ✗ | 部分 | **✓** |
| 算出的重量一定掛得出來 | ✗ | ✗ | **✓** |
| 記錄後自動開始休息計時 | ✗ | 部分 | **✓** |
| 免註冊、無廣告 | 不一定 | 多半要註冊 | **✓** |
| 免安裝，加到主畫面就能用 | ✗ | ✗ | **✓**（PWA） |

**我們的原則：**
- **只做練習當下需要的事**：沒有課表系統、社群或付費功能。
- **資料只存在你的手機上**：不用帳號，不會上傳雲端。
- **記錄只保留今天**：練完複製帶走，隔天打開就是新的一頁，不會越積越多。
- **自動更新**：新版上線後打開就會更新，不用重新安裝。
